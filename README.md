# 🏠 หอพักเทาทอง — ระบบลงทะเบียนหอพักออนไลน์

เว็บสำหรับลงทะเบียนเข้าพักหอพักนิสิต ครบตั้งแต่สมัคร เลือกห้อง ชำระเงิน รับใบเสร็จ แจ้งซ่อม คุยกับเจ้าหน้าที่ ไปจนถึงหลังบ้านสำหรับผู้จัดการหอ

> ⚠️ **ตอนนี้เป็นเว็บทดสอบ:** การชำระเงินเป็นแบบจำลอง (ไม่ตัดเงินจริง) และข้อมูลการเดินทาง สวัสดิการ ตำแหน่งตึกบนแผนที่ ยังเป็นข้อมูลตัวอย่าง **ห้ามกรอกข้อมูลส่วนตัวจริง**

## 🚀 โหลดและเปิดใช้งาน (Windows)

วิธีนี้ **ไม่ต้องลงโปรแกรมเขียนโค้ดใด ๆ** ใช้แค่ Docker Desktop

### ขั้นที่ 1 — ติดตั้ง Docker Desktop (ทำครั้งเดียว)

1. ดาวน์โหลดที่ <https://www.docker.com/products/docker-desktop/> แล้วติดตั้ง
2. เปิด Docker Desktop หนึ่งครั้งให้ตั้งค่าเสร็จ (ถ้าขอให้รีสตาร์ทเครื่อง ให้รีสตาร์ท)

### ขั้นที่ 2 — โหลดโปรเจกต์

**แบบง่าย (ไม่ต้องใช้ Git)**
1. เข้า <https://github.com/Re-Seth/web_dorm>
2. กดปุ่มสีเขียว **Code** → **Download ZIP**
3. คลิกขวาที่ไฟล์ ZIP → **Extract All** (ต้องแตกไฟล์ก่อน — เปิดจากใน ZIP ตรง ๆ จะใช้ไม่ได้)

**แบบใช้ Git**
```bash
git clone https://github.com/Re-Seth/web_dorm.git
```

### ขั้นที่ 3 — เปิดเว็บ

ในโฟลเดอร์ที่แตกไฟล์แล้ว **ดับเบิลคลิก `docker-start.bat`** แล้วรอ (ครั้งแรกประมาณ 3–10 นาที ครั้งต่อไปเร็วขึ้นมาก)

สคริปต์จะทำให้เองทั้งหมด: เปิด Docker, สร้างไฟล์ตั้งค่า, สำรองข้อมูลเดิม, สร้างและเปิดระบบ แล้วเปิดเบราว์เซอร์ให้ที่

### 👉 <http://localhost:8080>

- เครื่องอื่นที่ต่อ Wi-Fi/LAN เดียวกัน เปิดได้ด้วยลิงก์ที่สคริปต์แสดง เช่น `http://192.168.1.20:8080`
- ถ้าสคริปต์ถามว่าจะปิดโปรแกรมที่ใช้พอร์ต 5000 / 8080 อยู่ไหม ตอบ `y` เพื่อให้เปิดเว็บได้

### ปิดเว็บ

ดับเบิลคลิก **`docker-stop.bat`** — ข้อมูลไม่หาย เปิดใหม่ครั้งหน้าข้อมูลเดิมยังอยู่

### อัปเดตเป็นเวอร์ชันใหม่

โหลดโปรเจกต์ใหม่ (หรือ `git pull`) แล้วดับเบิลคลิก `docker-start.bat` อีกครั้ง — ข้อมูลเดิมยังอยู่ และระบบสำรองฐานข้อมูลไว้ในโฟลเดอร์ `backups\` ให้ก่อนอัปเดตทุกครั้ง

<details>
<summary><b>ใช้ Mac หรือ Linux?</b></summary>

ติดตั้ง Docker Desktop แล้วรันในโฟลเดอร์โปรเจกต์:

```bash
echo "JWT_SECRET=$(openssl rand -base64 48)" > .env   # ทำครั้งแรกครั้งเดียว
docker compose up -d --build                          # เปิดเว็บ → http://localhost:8080
docker compose down                                   # ปิดเว็บ
```
</details>

## 📖 วิธีใช้งาน

### เข้าระบบแบบทดลอง (ง่ายที่สุด)

เพิ่มบรรทัดนี้ในไฟล์ `.env` ที่โฟลเดอร์หลัก (ไฟล์นี้ถูกสร้างหลังรัน `docker-start.bat` ครั้งแรก) แล้วรัน `docker-start.bat` อีกครั้ง:

```
DEMO_LOGIN=true
```

หน้าเข้าสู่ระบบจะมีปุ่ม **ผู้เช่า** และ **ผู้จัดการหอ (Admin)** กดแล้วเข้าได้ทันที บัญชีผู้เช่าทดลองมีข้อมูลตัวอย่างให้แล้ว ลองจองห้อง จ่ายเงิน แจ้งซ่อมได้เลย

> ⚠️ ใช้กับเว็บทดสอบเท่านั้น — ใครก็กดเข้าเป็น Admin ได้

### ผู้เช่า: ลงทะเบียนเข้าพัก 4 ขั้นตอน

1. **สมัครเข้าพัก** — กดปุ่ม "ลงทะเบียน" บนหน้าแรก แล้วกรอกข้อมูลให้ครบ (ระบบสร้างบัญชีให้พร้อมกัน)
2. **เลือกห้องพัก** — ระบบแสดงเฉพาะอาคารตามเพศ: ชาย → เทาทอง 1 / หญิง → เทาทอง 2–4 กดห้องที่ยังว่างแล้วยืนยัน
3. **ชำระเงิน** — ค่าลงทะเบียน 1,999 บาท เลือก QR หรือโอนเงิน
4. **รับใบเสร็จ** — พร้อมบัตรผู้เช่าดิจิทัลในหน้าหลัก

| กติกา | |
|---|---|
| ช่วงเวลา | จองได้เฉพาะช่วงเปิดรับลงทะเบียน (ค่าเริ่มต้นถึง 31 มี.ค. 2570) |
| จำนวน | 1 คนจองได้ 1 ห้อง ห้องละ 4 เตียง |
| เปลี่ยนห้อง | เปลี่ยนได้จนกว่าจะชำระเงิน |

หลังเข้าพัก ใช้เมนู **ค่าไฟ & แจ้งซ่อม** เพื่อแจ้งซ่อม และปุ่ม 💬 มุมขวาล่างเพื่อถามคำถามหรือคุยกับเจ้าหน้าที่

### ผู้จัดการหอ

เข้าสู่ระบบด้วยบัญชี Admin แล้วระบบพาไปหน้า **ระบบจัดการหอพัก** ซึ่งมีแท็บ:
ภาพรวม · ผู้พัก & ห้อง · การชำระเงิน · แจ้งซ่อม · **แชทนิสิต** · สิทธิ์ผู้ใช้

ไอคอนบนแถบด้านบน: 💬 = แชทที่ยังไม่ได้อ่าน · 🔔 = แจ้งซ่อมใหม่

<details>
<summary><b>สร้างบัญชี Admin จริง (ไม่ใช้ปุ่มทดลอง)</b></summary>

เพิ่มในไฟล์ `.env` ที่โฟลเดอร์หลัก:

```
ADMIN_USERNAME=admin
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=ตั้งรหัสผ่านที่เดายาก
```

แล้วรัน `docker-start.bat` ตามด้วยคำสั่งนี้ใน PowerShell:

```bash
docker exec dorm_backend node prisma/seed.js
```
</details>

## 🌐 แชร์ให้คนอื่นลองใช้

ให้เพื่อนที่อยู่ที่ไหนก็ได้เข้าเว็บผ่านอินเทอร์เน็ต (ไม่ต้องตั้งค่าเราเตอร์):

1. เปิดเว็บด้วย `docker-start.bat` ให้เรียบร้อย
2. ดับเบิลคลิก **`share-tunnel.bat`** (ครั้งแรกจะถามเพื่อติดตั้งโปรแกรม `cloudflared` ให้ — ตอบ `y`)
3. จะได้ลิงก์หน้าตาแบบ `https://xxxx.trycloudflare.com` (คัดลอกไว้ให้แล้ว) ส่งให้เพื่อนได้เลย

- ต้อง **เปิดเครื่องและหน้าต่างนี้ค้างไว้** ตลอดที่แชร์ — ปิดหน้าต่างเมื่อต้องการหยุด
- เปิดใหม่แต่ละครั้งจะได้ลิงก์ใหม่

## 🧰 ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| ดับเบิลคลิก `.bat` แล้วหน้าต่างปิดทันที / ขึ้นว่าหาไฟล์ไม่เจอ | ยังไม่ได้แตกไฟล์ ZIP — คลิกขวา **Extract All** ก่อน แล้วเปิดจากโฟลเดอร์ที่แตกแล้ว |
| รอนานแล้วขึ้นว่า Docker ยังไม่พร้อม | เปิด Docker Desktop เองให้ขึ้นว่า *Engine running* แล้วรันใหม่ |
| ขึ้นว่าพอร์ต 8080 / 5000 ถูกใช้อยู่ | ตอบ `y` ให้สคริปต์ปิดตัวเก่าให้ หรือปิดโปรแกรมที่ใช้พอร์ตนั้นเอง |
| เครื่องอื่นในวง LAN เปิดไม่ได้ | ต้องต่อเครือข่ายเดียวกัน และอนุญาต Docker ใน Windows Firewall (Private network) |
| ปุ่มบัญชีทดลองไม่ขึ้น | ตรวจว่ามี `DEMO_LOGIN=true` ใน `.env` ที่โฟลเดอร์หลัก แล้วรัน `docker-start.bat` ใหม่ |
| จองห้องไม่ได้ | ต้องกรอกข้อมูลผู้เช่าก่อน, อยู่ในช่วงเปิดรับ, และห้องยังไม่เต็ม — ถ้าจ่ายเงินแล้วจะเปลี่ยนห้องไม่ได้ |

ดูข้อความผิดพลาดของระบบ: `docker compose logs -f backend`

## 🔩 ตั้งค่าเพิ่มเติม

ใส่ในไฟล์ **`.env` ที่โฟลเดอร์หลัก** แล้วรัน `docker-start.bat` ใหม่

| ตัวแปร | ค่าเริ่มต้น | ใช้ทำอะไร |
|---|---|---|
| `JWT_SECRET` | สุ่มให้อัตโนมัติ | กุญแจลับของระบบล็อกอิน — **ห้ามแชร์ ห้าม commit** |
| `DEMO_LOGIN` | `false` | `true` = มีปุ่มเข้าระบบทดลอง |
| `REG_TERM` | `ภาคเรียนที่ 2/2569` | ชื่อรอบลงทะเบียน |
| `REG_OPEN_AT` / `REG_CLOSE_AT` | 17 ต.ค. 2569 – 31 มี.ค. 2570 | ช่วงเปิดรับ เช่น `2027-03-31T23:59:59+07:00` |
| `REGISTRATION_FEE` | `1999` | ค่าลงทะเบียน (บาท) |
| `ADMIN_USERNAME` / `ADMIN_EMAIL` / `ADMIN_PASSWORD` | — | ใช้สร้างบัญชี Admin จริง |
| `CORS_ORIGIN` | `http://localhost:8080` | ใช้เมื่อแยกโดเมนหน้าเว็บกับ API |
| `TRUST_PROXY` | `2` | จำนวน proxy ข้างหน้า backend (ใช้จำกัดการเดารหัสผ่านตาม IP จริง) |

**แก้ข้อมูลที่แสดงบนเว็บ**
- คำตอบของแชทบอท / เบอร์ติดต่อ: [`dorm-registration/src/data/chatbot.js`](./dorm-registration/src/data/chatbot.js) (ใส่ข้อมูลจริงแล้วตั้ง `CHATBOT_IS_SAMPLE = false`)
- ข้อมูลอาคาร ราคา และพิกัดบนแผนที่: [`dorm-registration/src/data/landing.js`](./dorm-registration/src/data/landing.js) (ใส่พิกัดจริงแล้วตั้ง `MAP_IS_SAMPLE = false`)

**ข้อมูลและการสำรอง**
- ฐานข้อมูลเก็บใน Docker volume `web_dorm_dbdata` — ปิด/เปิดเว็บ ย้ายโฟลเดอร์ หรืออัปเดต ข้อมูลไม่หาย
- ข้อมูลจะหายเฉพาะเมื่อสั่ง `docker compose down -v` เท่านั้น
- ไฟล์สำรองอยู่ในโฟลเดอร์ `backups\` (เก็บ 5 ชุดล่าสุด, สร้างอัตโนมัติทุกครั้งที่รัน `docker-start.bat`)

## 💻 สำหรับนักพัฒนา

**เทคโนโลยี:** React 18 + Vite + Tailwind CSS (หน้าเว็บ) · Express + Prisma (SQLite) + Socket.io (API) · Leaflet (แผนที่) · three.js (ห้อง 3 มิติ) · Docker + Nginx

```
web_dorm/
├── dorm-registration/           หน้าเว็บ (React)
│   └── src/
│       ├── pages/               หน้าต่าง ๆ รวม Admin/
│       ├── components/          ส่วนประกอบ (landing, chat, tenant, Layout)
│       └── data/                ข้อมูลที่แก้ได้ (chatbot.js, landing.js, dorms.js)
├── dorm-registration-backend/   API (Express)
│   ├── index.js                 จุดเริ่ม: บัญชีผู้ใช้, แจ้งซ่อม, Socket.io
│   ├── *Routes.js               API แยกตามเรื่อง (ผู้เช่า, admin, แชท, โปรไฟล์)
│   └── prisma/schema.prisma     โครงสร้างฐานข้อมูล
├── docker-compose.yml
├── docker-start.bat / docker-stop.bat / share-tunnel.bat
└── start.bat / start.js         รันแบบไม่ใช้ Docker
```

### รันแบบไม่ใช้ Docker (ต้องมี Node.js 20+)

ดับเบิลคลิก **`start.bat`** หรือรัน `npm start` ที่โฟลเดอร์หลัก — สร้าง `.env`, ติดตั้งแพ็กเกจ, สร้างฐานข้อมูล แล้วเปิด <http://localhost:5173> ให้เอง

<details>
<summary><b>รันทีละส่วนเอง (manual)</b></summary>

```bash
# Backend — port 5000
cd dorm-registration-backend
npm install
cp .env.example .env        # ตั้ง JWT_SECRET อย่างน้อย 16 ตัวอักษร
node prisma/prepare-db.js   # เก็บกวาดข้อมูลเก่าที่ขัดกับ schema
npx prisma db push          # สร้าง/อัปเดตตาราง
npm run dev

# Frontend — port 5173 (เปิดอีกเทอร์มินัล)
cd dorm-registration
npm install
npm run dev
```

สร้างค่า `JWT_SECRET`: `node -e "console.log(require('crypto').randomBytes(48).toString('base64'))"`

ถ้า backend ไม่ได้อยู่ที่ `http://localhost:5000` ให้ตั้ง `VITE_API_URL` ให้หน้าเว็บ
</details>

ผ่าน Docker เรียกที่ `http://localhost:8080/_api/...` (nginx ส่งต่อให้ backend)

**บัญชีผู้ใช้**

| Method | Endpoint | คำอธิบาย |
|---|---|---|
| POST | `/register` | สมัครสมาชิก (รหัสผ่าน ≥ 8 ตัวอักษร) |
| POST | `/login` | เข้าสู่ระบบด้วย username หรืออีเมล (JWT อายุ 1 วัน) |
| POST | `/logout` | ออกจากระบบ 🔒 |
| POST | `/change-password` | เปลี่ยนรหัสผ่าน — token เก่าใช้ไม่ได้ทันที 🔒 |
| GET | `/me` | ข้อมูลผู้ใช้ปัจจุบัน 🔒 |
| GET | `/check-username/:name` | username ว่างหรือไม่ |
| GET | `/users` | รายชื่อผู้ใช้ (แบ่งหน้า) 🔒👑 |
| GET / PUT / DELETE | `/users/:id` | ดู/แก้ไข/ลบ — ของตัวเอง หรือ Admin 🔒 |
| GET / POST | `/api/demo-login` | บัญชีทดลอง (เมื่อ `DEMO_LOGIN=true`) |

**Real-time (Socket.io)** — แนบ token ใน `auth.token` ตอนเชื่อมต่อ
- `power_update` — ข้อมูลไฟฟ้าทุก 3 วินาที (ทุกคน)
- `maintenance_created` / `maintenance_updated` — เฉพาะ Admin และผู้แจ้ง
- `chat_message` / `chat_updated` — เฉพาะ Admin และเจ้าของห้องแชท

<summary><b>ความปลอดภัย</b></summary>

- ห้าม commit `.env` และไฟล์ฐานข้อมูล `*.db` (อยู่ใน `.gitignore` แล้ว)
- ทุกคำขอตรวจสิทธิ์ล่าสุดจากฐานข้อมูล — ลดสิทธิ์/ลบบัญชีมีผลทันที, เปลี่ยนรหัสผ่านแล้ว token เก่าใช้ไม่ได้
- จำกัดการล็อกอินผิด 10 ครั้ง / 15 นาที ต่อ IP + บัญชี และจำกัดความถี่การสมัคร แจ้งซ่อม และแชท
- การจองทำใน transaction กันจองเกินความจุและกันจองซ้อนเมื่อกดพร้อมกันหลายคน
- ลบบัญชี → ลบข้อมูลส่วนตัว รีวิว แจ้งซ่อม แชท และคืนเตียงอัตโนมัติ
- ก่อนใช้งานจริง: ปิด `DEMO_LOGIN`, เปลี่ยนการชำระเงินเป็นแนบสลิปให้ Admin ยืนยัน
</details>
